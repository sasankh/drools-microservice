## PROBLEM SOLVING
- **Healthcheck regression (P1)**: protecting all `/admin/*` made the keyless container healthcheck
  401 → unhealthy. Fixed compose + Dockerfile healthcheck to send `X-Admin-API-Key`/`$ADMIN_API_KEY`.
- **Timeout mapped to 400 not 408**: found live in Phase 3; controller catch-all wrapped
  `TimeoutException`. Added dedicated `catch (TimeoutException | ServiceUnavailableException)`.
- **E2E redis-off 404**: test-harness race (executed before rules loaded — waited on actuator
  liveness not readiness). Re-verified with container-health wait → 200. Not a product bug.
- **Config wrinkle noted (not fixed)**: docker/dev/prod profiles hardcode `redis.enabled: true`,
  shadowing the `REDIS_ENABLED` env var for the app (only `management.health.redis.enabled` reads the
  env directly). Pre-existing; out of scope.
