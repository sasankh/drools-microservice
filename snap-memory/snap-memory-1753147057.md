## ❌ **ERRORS ENCOUNTERED & SOLUTIONS** - Problems and Resolutions

### 1. Initial .env Library Selection Issue
**Problem**: First attempted `spring-dotenv` library, import failures
```java
// FAILED
import me.paulschwarz.springdotenv.environment.DotenvPropertySource;

// SOLUTION - Switched to standard dotenv-java
import io.github.cdimascio.dotenv.Dotenv;
```

### 2. JSON Type Casting in Rule Execution
**Problem**: JSON sends Integer (100), Drools expects Double
```
ClassCastException: class java.lang.Integer cannot be cast to class java.lang.Double
```
**Solution**: Use decimal notation (100.0) in JSON requests
**Analysis**: Design consideration - document requirement or add type conversion

### 3. Admin Endpoint Routing Configuration
**Problem**: Custom admin endpoints not accessible, routing to static resources
```
NoResourceFoundException: No static resource admin/rules.
```
**Solution**: Identified as Phase 3 configuration work item
**Impact**: Low - basic health endpoints work, custom APIs need configuration fix

### 4. Validation Error Message Format
**Problem**: Initial API test used `ruleId` instead of `rule_id`
```json
{"ruleId": "simple.discount", "data": {"amount": 100}}
```
**Solution**: Corrected to use underscore format as defined in DTO
```json
{"rule_id": "pricing.discount.simple", "data": {"amount": 100.0}}
```
